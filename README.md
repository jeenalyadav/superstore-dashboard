# Superstore Sales Dashboard

## Overview
This project analyzes retail sales data to uncover business insights related to revenue, profit, and customer behavior using an interactive dashboard.

## Objectives
- Analyze sales and profit trends
- Identify high-performing and low-performing regions
- Understand category-wise performance
- Support business decision-making through data visualization

## Dataset
- Source: Sample Superstore Dataset
- Features: Order Date, Sales, Profit, Category, Region, Customer Segment, etc.

## Tools Used
- Power BI / Tableau / Excel (mention yours)
- Data Cleaning & Transformation

## Key Insights
- West region generates highest sales but lower profit margins
- Technology category is most profitable
- Some sub-categories (like Tables) consistently incur losses
- Discounts negatively impact profit

## Dashboard Features
- Interactive filters (Region, Category, Segment)
- Drill-down analysis
- KPI cards (Sales, Profit, Orders)
- Time-series trend analysis

## Business Recommendations
- Reduce discounts on low-margin products
- Focus on high-profit categories like Technology
- Improve supply chain for loss-making sub-categories

## How to Use
1. Download the dashboard file
2. Open in Power BI / Tableau
3. Use filters to explore insights
